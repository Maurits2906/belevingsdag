# Belevingsdag AI
In deze repository vindt u alles voor de belevinsdag voor het gedeelte AI.

## Wat moet je gaan maken?
Je gaat beginnen om je eigen AI chatbot te maken met Python. Daarna ga je de inhoud van een website lezen met Python. Als laatste stap ga je jouw eigen Zoekopdracht automatiseren. Vanaf daar ben je vrij om een AI automatisering te maken met Python die jij leuk vindt.

 ## Inhoud : 
-  Presentatie
-  Stap 1 : Maak je eigen chatbot (basis oplossing is gegeven)
-  Stap 2 : Scrape data van een eigen website naar keuze (basis oplossing is gegeven)
-  Stap 3 : Automatiseer jouw eigen opzoekwerk (basis oplossing is gegeven)
